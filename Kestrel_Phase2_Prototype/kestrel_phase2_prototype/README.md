# Kestrel — Phase 2 Prototype

Extends the Phase 1 lexer/parser with function declarations, calls, and return
statements, and adds the Phase 2 pipeline stages: a nested-scope Symbol Table,
a Semantic Analyzer, and a Bytecode Generator producing Kestrel's stack-based IR.

## Build
```
javac -d out src/kestrel/*.java
```

## Run
```
java -cp out kestrel.Main samples/sample5_functions_recursion.kes
java -cp out kestrel.Main samples/sample6_scope_and_shadowing.kes
java -cp out kestrel.Main samples/sample7_semantic_errors.kes
```

Each run prints the source, the parse tree, the symbol table dump, and (if no
semantic errors are found) the generated bytecode listing for every function
plus the top-level "main" chunk.

See sample_run_output.txt for a captured run of all three samples, which is
also reproduced in the Phase 2 report.

Execution of the generated bytecode (the stack-based Virtual Machine with call
frames) and the optimization pass are implemented in Phase 3.
